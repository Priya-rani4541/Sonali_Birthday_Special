# Sonali's Birthday Surprise 🎂

React + Vite + Tailwind CSS + Framer Motion.

## Run
    npm install
    npm run dev

## Add your files to `src/assets/`
- Photos: `sonali1.png`, `sonali2.png`, `sonali3.png` ... (sonali1 is the hero photo)
- Videos: `video1.mp4`, `video2.mp4`, ...
- Birthday celebration video (with sound): `celebration.mp4`
- Music (optional): `music.mp3` — the player appears only when this file exists.

If no music.mp3 is added, a soft built-in lullaby plays instead.
Files are detected automatically and sorted by number. Edit the letter text and photo
captions at the top of `src/App.jsx`. Build for hosting with `npm run build` (output in `dist/`).
- Edit birthday date, quiz, letters, gifts, timeline, reasons and wishes in src\/data.js
